# خطة تنفيذ مآل

## P0

- تثبيت المسارات وتحميل البيئة بلا كشف الأسرار.
- إضافة migrations وتهيئة قاعدة البيانات عند البدء.
- إدخال `run_id` و`finding_id` والمفاتيح الفريدة ومنع تكرار التشغيل والمهمة.
- فرض عقود Pydantic وحالات `unknown` و`insufficient_evidence` و`conflicting_evidence`.
- منع المهمة العلاجية عند غياب دليل كافٍ.
- فصل مدخلات الديمو عن `gold labels` وإزالة العبارات التي تكشف الإجابة.

## P1

- سجل مصادر ونسخ غير قابلة للاستبدال ببصمة SHA-256.
- استخراج مواد ومقارنة الإضافة والحذف والقيم والموعد والنطاق والتحرير.
- آلة حالات دائمة مع `thread_id` واستئناف وحد محاولتين للاسترجاع.
- API غير متزامن، أدوار أساسية، CORS مقيد، ومراجعة بشرية مع `expected_revision`.
- واجهة عربية لمسار المادة والدليل والفجوة والمهمة وسجل التدقيق.

## P2

- تقرير ديناميكي من البيانات المثبتة دون إعادة اختراع النتائج.
- تحسين تجربة العرض والقياسات التشغيلية.
- إضافة موصلات رسمية وPostgreSQL وعامل طابور عند الانتقال من الديمو.
